# ДЗ к ЛК4 PyQt

Описание проекта:  
Графическое приложение для отображения профиля пользователя с аватаром и планеты Земля реализованное с помощью Python и PyQt6.

## Стек технологий

- **Язык программирования:** Python 3.11+
- **Графическая библиотека:** PyQt6 

## Быстрый старт

1. Склонируйте репозиторий:
2. Установите отдельные пакеты: `pip install PyQt6`
3. Запустите приложение

## Структура проекта

- `/images` — ресурсы (аватарки, иконки)
- `profile.py` — скрипт для профиля
- `README.md` — этот файл
- `planet.py` — скрипт для планеты

## Особенности

- Красивый GUI для отображения профиля пользователя
- Круглый аватар с маской (на базе PyQt6)
- Адаптивные шрифты и цветовая схема
